## Overview

Mason James has created a tutorial video demonstrating the /rp-build workflow, which provides a simplified interface for rapid feature development.

## Workflow

According to Eric Provencher's explanation:

1. **Setup MCP:** Configure the MCP (Model Context Protocol) environment
2. **Build Task:** Use `/rp-build {task}` command to automatically handle the full build process
3. **Review:** Use `/rp-review` command to review changes and validate the work

## Key Features

- Simplified command-based workflow
- Automated task execution
- Built-in review mechanism
- Designed for developers familiar with XML Edit-style workflows

## Use Case

The workflow simplifies the process of implementing new features into a project, making it more intuitive for users coming from earlier CLI workflow styles.
