An agent skill that transforms complex terminal output, text-based plans, and explanations into styled HTML pages you actually want to read. Generates self-contained interactive HTML with Mermaid diagrams, responsive design, and dark/light theme support.

## Key Features

- Converts ASCII art and text tables into rich HTML visualizations
- Generates interactive Mermaid diagrams with zoom and pan
- Includes slash commands for diff reviews, plan reviews, and project recaps
- Maintains consistent design with CSS pattern library and reference templates
- Supports architecture diagrams, data comparisons, and decision logs
- Dark/light theme support with professional typography
- No build step or external dependencies

## Use Cases

- `/diff-review` - Visual diff analysis with before/after architecture diagrams and code review
- `/plan-review` - Compare implementation plans against actual codebase with risk assessment
- `/project-recap` - Generate mental model snapshot for context switching
- `/generate-web-diagram` - Create HTML diagrams for any topic
- `/fact-check` - Verify documentation accuracy against source code
