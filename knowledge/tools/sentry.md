# Sentry

**Project:** Sentry CLI / npm package
**URL:** https://www.npmjs.com/package/sentry
**Type:** Error Tracking & Monitoring Tool
**Status:** Active

## Overview
Sentry is an error tracking platform and CLI tool for monitoring application crashes and performance issues. Used for crash triage and automated issue analysis.

## Use Cases
- Polling for crashes and application hangs
- Issue triage automation
- Integration with AI tools for automated fix planning
- Real-time error tracking and reporting

## Integration with AI/MCPs
- Works with Claude through MCPs for automated issue analysis
- Can be integrated with @RepoPrompt CLI for generating fix plans
- Supports parallel processing of multiple issues

## Tools That Work With It
- [[repo-prompt-cli]] - AI-powered repository analysis tool
- [[claude-mcp]] - Integration via Model Context Protocol
