Official Claude Code compound engineering plugin marketplace featuring tools designed to make each unit of engineering work easier than the last. The plugin is cross-compatible with multiple AI coding environments including Claude Code, OpenCode, Codex, Factory Droid, Cursor, Pi, and Gemini CLI.

## Key Features

- Claude Code plugin marketplace integration
- Multi-platform support with format conversion (OpenCode, Codex, Droid, Pi, Gemini, Copilot, Kiro)
- Compound workflow system (Plan → Work → Review → Compound → Repeat)
- Features include:
  - `/workflows:plan` - Turn feature ideas into detailed implementation plans
  - `/workflows:work` - Execute plans with worktrees and task tracking
  - `/workflows:review` - Multi-agent code review before merging

## Platform Integration

- **Claude Code:** Native plugin installation
- **Cursor:** Native plugin support
- **OpenCode/Codex/Droid/Pi/Gemini:** Via conversion CLI with `@every-env/compound-plugin`
- **GitHub Copilot:** Format conversion available
- **Kiro CLI:** Experimental support
