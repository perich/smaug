# dot314

**Repository:** https://github.com/w-winter/dot314

**Description:** Extensions, commands, themes for Pi agent

**Language:** TypeScript

**Stars:** 38

## Overview

Tools and accessories for the Pi coding agent, with emphasis on making Pi and RepoPrompt co-operate well.

## Components

### Extensions

Notable extensions include:
- `brave-search/` - web search with Brave API
- `editor-enhancements/` - UI improvements
- `repoprompt-mcp/` - MCP adapter for RepoPrompt (featured tool)
- `rp-native-tools-lock/` - Native tools integration
- `vog/` - visualization tools
- `guardrails/` - safety boundaries
- `sandbox/` - isolated execution

### Skills

- Text search integration
- Development browser
- Build system integration (xcodebuild)

### Themes

- Violet Dawn
- Violet Dusk

## Installation

### As Pi Package (0.50.0+)

```bash
pi install git:github.com/w-winter/dot314
# or with raw URL:
pi install https://github.com/w-winter/dot314
```

Test without installing:
```bash
pi -e git:github.com/w-winter/dot314
```

### Individual Extensions via npm

```bash
pi install npm:pi-repoprompt-cli
```

### Manual/Symlink Setup

```bash
git clone git@github.com:w-winter/dot314.git ~/path/to/dot314-agent
ln -s ~/path/to/dot314-agent/extensions/repoprompt-cli.ts ~/.pi/agent/extensions/
```

## MCP Adapter

The `repoprompt-mcp/` extension adapts @nicopreme's MCP adapter for use with the Pi agent, allowing RepoPrompt queries to be executed within Pi's context.
