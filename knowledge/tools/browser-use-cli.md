# Browser Use CLI + Skill

100% open-source browser automation tool for Claude Code and Codex agents.

- **Repository:** https://github.com/gregpr07/browser-use (implied from tweet)
- **Installation:** 2-line skill install
- **Purpose:** Give agents a real browser for local development tasks

## Supported Modes
- Headless mode (fast)
- Real Chrome with logins
- Cloud browsers with proxies and anti-detection

## Use Case
Perfect for local dev tasks where an agent can:
- Navigate to localhost:3000
- Identify UI issues
- Iterate and improve design

## Skills Integration
Works with Claude Code and Codex agents via skill system.
