# Remotion Agent Skills - Video Creation with Claude Code

Remotion now offers Agent Skills integration, enabling video creation directly through Claude Code prompting.

## Installation

```bash
$ npx skills add remotion-dev/skills
```

## Capabilities

- Create animations via natural language prompting
- Integrated with Claude Code for agent-driven video generation
- No manual animation code required

## Example

The announcement includes a demonstration where a complex animation was created purely through prompting without explicit code writing.

## Use Cases

- AI-generated video content for web applications
- Animated marketing materials
- Dynamic visual demonstrations
