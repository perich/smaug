# Agentation

Visual feedback tool for agents that helps with element inspection and interaction.

- **npm:** `npm i agentation`
- **Repository:** https://github.com/benjitaylor/agentation
- **Features:**
  - Click elements to add notes
  - Copy markdown
  - Get element paths and selectors
  - Provides positioning and context for agents

## Use Case
Ideal for providing visual feedback to AI agents during UI interaction tasks. Agents can click elements, receive paths and selectors, and understand page structure for automated improvements.
