# Pi Web Access

GitHub repository for a Pi agent tool with video understanding capabilities.

## Features

- Video understanding for AI agents
- Works with Gemini in Chrome without needing API keys
- Can analyze YouTube URLs or local video files (mp4, mov, etc)
- Install via: `pi install npm:pi-web-access`

## Key Use Case

Enables AI agents running on Raspberry Pi to understand and analyze video content, querying specific information from YouTube videos or local video files.
