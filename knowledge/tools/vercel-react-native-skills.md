# Vercel React Native Skills

## Overview
Vercel React Native Skills is an agent-oriented toolkit for building React Native applications with native performance. It extracts lessons learned from building v0 for iOS and Vercel's upcoming native app.

## Features
- Fast list rendering
- Smooth animations
- Native feel and performance
- Built with React Native and Expo experience

## Installation
```bash
npx skills add vercel-labs/agent-skills
```

## Use Cases
- Agent-based React Native development
- Cross-platform mobile app building
- Native performance-critical features

Released by Vercel in January 2026, with contributions from Fernando Rojo highlighting React Native and Expo expertise.
