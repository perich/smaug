# Echo 13 Thunderbolt 5 SSD Dock

**Product URL:** https://www.sonnettech.com/product/echo13-thunderbolt5-ssd-dock/overview.html
**Manufacturer:** Sonnet Technologies
**Product Line:** Thunderbolt Docks

## Overview

The Echo 13 Thunderbolt 5 SSD Dock is the industry's first shipping Thunderbolt 5 dock with integrated SSD storage. It combines a comprehensive docking solution with built-in PCIe 4.0 NVMe SSD storage options for users requiring both connectivity and storage expansion.

## Key Specifications

- **Connection Standard:** Thunderbolt 5
- **Built-in Storage:** PCIe 4.0 NVMe SSD options (including versions with and without included SSD)
- **Additional Connectivity:**
  - 10Gbps USB ports
  - 2.5GbE Ethernet
  - SD and microSD card readers
  - 140W power delivery
  - Support for up to 8K displays

## Target Use Cases

The Echo 13 is designed for professional users requiring:
- Fast external storage through Thunderbolt 5
- Comprehensive peripheral connectivity
- High power delivery for charging and peripheral support
- Multi-monitor setups with 8K display support
