# Better Context (btca)

**URL:** https://btca.dev | **GitHub:** https://github.com/bmdavis419/better-context

CLI and web app for answering questions about real codebases using actual source code retrieval.

## Status
Production-ready (as of Jan 2026). Available across:
- CLI tool
- Web application
- MCP server

## Key Features
- Search real repositories with natural language queries
- Answers grounded in actual source code (not hallucination-based)
- MCP server integration for AI agents
- Web UI for interactive exploration

## Use Cases
- Learning about technology from actual source implementations
- Code context lookup for AI-assisted development
- Codebase analysis and understanding

## Notes
- Creator (Ben Davis) recently migrated the btca agent to custom AI SDK with "Just Bash" package
- Resources virtualized into memory for better performance
- Strong focus on simplifying resource management and collection structures
- MCP server integration is particularly effective for agent-based workflows
