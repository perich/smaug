# Pencil - Design on Canvas, Land in Code

## Overview
Pencil is a design-to-code tool that fundamentally increases engineering speed by bringing design directly into your preferred IDE. It allows designers and developers to collaborate on designs that compile to code.

## Key Features
- **Infinite WebGL Canvas** - Superfast, fully editable design canvas
- **Parallel Design Agents** - Multiple agents can work simultaneously on designs
- **Local Execution** - Runs locally with Claude Code
- **Git Integration** - Design files live in your git repo as JSON-based `.pen` format
- **IDE Integration** - Works with Claude Code and Cursor
- **Code Generation** - Turns designs directly into code

## Availability
- Available for Mac and Linux
- Compatible with Cursor
- Integrates with Claude Code
