App Store Connect CLI (asc) is a fast, lightweight, and scriptable CLI for automating iOS, macOS, tvOS, and visionOS release workflows. It provides JSON-first output without interactive prompts, making it ideal for CI/CD pipelines and automation.

## Key Features

- Automate TestFlight management, builds, and submissions
- Screenshot and metadata management
- Signing and bundle ID operations
- Analytics and feedback/crash retrieval
- Scriptable with JSON-first output
- GitHub Actions, GitLab CI, Bitrise, and CircleCI integrations
- Workflow automation support
- Custom configuration via react-doctor.config.json
- Homebrew and shell installation support
