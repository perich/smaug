# Skills Directory - The Agent Skills Ecosystem

## Overview
Skills is an open ecosystem providing reusable capabilities for AI agents. Skills can be installed with a single command to enhance agents with procedural knowledge and specialized functionality.

## Key Concepts
- **Single Command Installation** - Install skills with `npx skills add <owner/repo>`
- **Procedural Knowledge** - Skills encapsulate specialized capabilities and workflows
- **Multi-Agent Support** - Works across multiple AI agents and IDEs
- **Extensible** - Community-driven ecosystem for sharing agent capabilities

## Supported Agents & IDEs
The directory supports skills for:
- Claude Code
- Cursor
- VS Code
- Windsurf
- OpenCode
- Vercel (AMP)
- Antigravity
- Copilot
- Droid
- Gemini
- And many more

## Example Use Cases
- **Remotion Skills** - Create launch videos with Claude Code
  - Install: `npx skills add remotion-dev/skills`
  - Supports video timing, clips, transitions adjustments
