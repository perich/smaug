# Conductor - AI Orchestrator for Coding Agents

## Overview
Conductor is an AI orchestrator platform designed for running teams of coding agents on Mac. It enables developers to create parallel Codex and Claude Code agents in isolated workspaces, allowing them to see what each agent is working on and review/merge changes.

## Key Information
- **Status:** Launched mid-2025
- **Growth:** 250% growth in January 2026
- **Funding:** Raised $2.8M from top Silicon Valley investors
- **Users:** Used by engineers at companies like Linear, Vercel, Ramp, Notion, Stripe, and Y Combinator

## Vision
Conductor aims to be the primary UI for AI-managers/orchestrators. The team believes that as coding agents become more capable (currently handling junior engineer work, moving toward senior engineer work), the orchestration layer becomes critical. They position Conductor as the best AI orchestrator built ground-up with AI in mind.

## Work Culture
- In-person team (~5 days/week in San Francisco)
- Described as an "elite sports team" environment
- Focus on technical excellence, customer focus, taste, and speed

## Capabilities
- Run multiple coding agents in parallel
- Isolated workspaces for different agents
- Review and merge agent changes
- Orchestrate Codex and Claude Code agents
