Pup is a comprehensive, AI-agent-ready CLI with 200+ commands across 33+ Datadog products. It gives AI agents and engineers full access to Datadog's observability platform with self-discoverable commands and structured output for easy parsing. Pup makes Datadog accessible to AI-native workflows with 100% documented API coverage.

## Key Features

- 200+ commands across 33+ Datadog products
- Self-discoverable commands (no documentation hunting)
- Structured JSON/YAML output for easy parsing
- OAuth2 + PKCE for scoped access (no long-lived keys)
- Full coverage of monitoring, metrics, logs, RUM, security, and more
- AI-agent optimized with clear command patterns
- Support for Monitors, Dashboards, SLOs, Synthetics, Downtimes, Notebooks, Status Pages, and extensive observability features
