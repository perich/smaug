# course-video-manager

**Repo:** https://github.com/mattpocock/course-video-manager

A TypeScript project managed by Matt Pocock demonstrating autonomous agent capabilities through issue management.

## What It Does

The repository showcases autonomous agent testing through:
- Automated issue reporting and resolution
- Autonomous loop execution (agent runs same prompt 50+ times)
- Issue tracking and closure automation

## Notable Feature

Matt Pocock's autonomous agent (Ralph) successfully:
- Ran the same prompt 50+ times in an autonomous loop
- Closed all reported issues without manual intervention
- Demonstrated effective autonomous debugging and problem-solving

## Tech Stack

- TypeScript
- GitHub Issues API integration
- 64 stars on GitHub

## Relevance

Demonstrates the capability of coding agents to work autonomously and iteratively solve problems, particularly useful for:
- Autonomous bug fixing
- Issue resolution automation
- Long-running agent testing
