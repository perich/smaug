# Ariana

Platform for managing and orchestrating multiple AI coding agents across different infrastructure types.

## Key Features
- Launch and manage Claude Code agents across web, mobile, and desktop
- Support for multiple infrastructure backends (VPS, cloud servers)
- Wraps infrastructure providers like Hetzner VPS, planned support for Mac minis and Windows+GPU instances
- Provides snapshots and git integration
- Full persistent environments for agents

## Infrastructure Support
- Hetzner VPS wrapping (currently primary)
- Planned: Cloud Mac minis, Windows + GPU instances
- Can run desktop displays and streaming
- Full Docker support

## Advantages Over Alternatives
vs. Fly.io/Sprite:
- More cost-effective compute pricing
- Direct IP access (not HTTP-only)
- Full Docker support without workarounds
- Desktop display + streaming support
- Better multi-platform coverage

## Use Cases
- Building teams of AI agents working across different operating systems
- Long-running agent sessions with persistent state
- Multi-platform orchestration beyond just Linux/terminal environments
