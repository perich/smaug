# exe.dev - Persistent Virtual Machines via SSH

## Overview
exe.dev is a cloud development platform that enables launching persistent virtual machines with persistent disks in seconds via SSH command line interface.

## Key Features
- **Instant VMs**: Start persistent virtual machines in seconds
- **Persistent Storage**: Disk persists across sessions
- **Full Sudo Access**: Complete administrative control
- **SSH Interface**: Native SSH access (e.g., `ssh exe.dev`)
- **Phone-Friendly**: Enables coding from mobile devices

## Use Cases
- Remote development and prototyping
- Local development without local setup overhead
- Cloud-based coding environments
- Collaborative development with persistent state
