Terragon is an open-source snapshot of a remote background agent orchestrator for running Claude Code, Codex, and other coding CLIs in the cloud. Though the service is no longer active, the open-source codebase provides valuable reference architecture for building similar systems. The UI and architecture are well-designed and can be adapted for different infrastructure needs.

## Key Features

- Multi-agent support (Claude Code, OpenAI Codex, Amp, Gemini)
- Sandbox isolation with containerized environments
- Seamless Git workflow with automatic branching and PR generation
- Local handoff capability via terry CLI tool
- MCP (Model Context Protocol) server for task management
- Real-time task status streaming and browser notifications
- Integration with existing workflows via Slack and GitHub mentions
