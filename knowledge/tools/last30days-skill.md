# /last30days Claude Code Skill

**GitHub:** https://github.com/mvanhorn/last30days-skill
**Stars:** 2180
**Language:** Python

## Overview
A Claude Code skill that researches any topic across Reddit, X, and the web from the last 30 days, discovers what the community is actually discussing and sharing, and writes copy-paste-ready prompts that work with today's tools and techniques.

## Key Features
- **Cross-platform research:** Scans Reddit, X, and the broader web for recent discussions
- **Pattern synthesis:** Identifies trending techniques, best practices, and what actually works
- **Prompt generation:** Creates ready-to-use prompts for ChatGPT, Midjourney, Claude, Figma AI, etc.
- **Trend discovery:** Find viral techniques, community recommendations, and current best practices

## Installation
```bash
git clone https://github.com/mvanhorn/last30days-skill.git ~/.claude/skills/last30days
mkdir -p ~/.config/last30days
# Add API keys (OpenAI, XAI)
```

## Usage
```
/last30days [topic]
/last30days [topic] for [tool]
```

Examples:
- `/last30days prompting techniques for ChatGPT for legal questions`
- `/last30days iOS app mockups for Nano Banana Pro`
- `/last30days remotion animations for Claude Code`
