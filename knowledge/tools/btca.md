# Better Context (btca)

**Website:** https://btca.dev

**Repository:** https://github.com/bmdavis419/better-context

**Description:** CLI and web app for answering questions from real source code

## Overview

Better Context helps you ask questions about real codebases with context-aware answers grounded in source code. Available as both CLI and web app.

## Features

- Setup multiple git repos as "resources"
- Reference them in chat UI with "@"
- Powered by Haiku 4.5 for fast responses
- Pricing: $8/mo for hosted version, CLI is bring-your-own-key (BYOK)
- Open source

## Pricing & Deployment

- **Web App:** $8/month for hosted version
- **CLI:** Free (BYOK - bring your own Claude API key)
- **Source:** Open source, self-hostable

## Usage Pattern

1. Setup git repos as knowledge resources
2. Reference them with "@" syntax in chat
3. Ask questions and get context-aware answers from actual source code
