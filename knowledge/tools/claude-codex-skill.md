# Claude Code Codex Skill

**Source:** https://gist.github.com/antirez/2e07727fb37e7301247e568b6634beff

A skill file that enables Claude Code to use Codex when facing certain challenges. This approach allows combining Claude's capabilities with Codex for optimal problem-solving in edge cases.

**Key insight:** By explaining how to use Codex, Claude Code can leverage both Claude and Codex capabilities to handle complex issues that either tool alone might struggle with.

**Related:** Claude Code integration, agent capabilities, tool enhancement
