# Pigeon MCP - Claude Terminal Trading Integration

Claude terminal is now a trading terminal for Base, Solana, Polymarket, Hyperliquid and more via the pigeon-mcp (Model Context Protocol).

## Features

Agent-capable trading terminal with multi-chain support:
- Base, Solana, Polymarket, Hyperliquid integration
- Natural language trading queries
- Real-time monitoring and alerts

## Example Use Cases

- "Find base or sol coins with >$1M volume and buzz on CT and Farcaster"
- "Alert me when polymarket contract [xyz] moves 10%+"
- "Long BTC with 1.3x leverage on Hyperliquid at 200 week moving average"

## Installation

```bash
$ npx pigeon-mcp
```
