# Using Linters to Direct Agents

## Source
- **URL:** https://factory.ai/news/using-linters-to-direct-agents
- **Author:** Factory.ai
- **Date:** January 21, 2026

## Key Concept
Linters can be used as a powerful mechanism to encode architecture, boundaries, and ergonomics directly into the code generation loop for AI agents. Rather than just catching errors after the fact, linters guide agents during generation.

## Relevance
This is critical for Agent Readiness - the ability to give agents fast feedback on whether they're building things correctly. Linters provide immediate validation that agents can learn from, enabling them to self-correct and verify their own work without waiting for CI.
