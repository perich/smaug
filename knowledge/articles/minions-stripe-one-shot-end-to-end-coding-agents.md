Minions are Stripe's homegrown coding agents responsible for more than a thousand pull requests merged each week. Though humans review the code, minions write it from start to finish. This article explores how Stripe built and deployed these autonomous agents to handle end-to-end coding tasks, introducing the concept of "pair prompting" as a new development methodology that complements traditional pair programming.

## Key Takeaways

- Stripe's minions have merged over 1,000 PRs per week with human review
- AI agents can autonomously handle entire development workflows from start to finish
- "Pair prompting" represents a new paradigm in software development alongside pair programming
- Integration of AI agents into development requires proper human oversight and code review processes
