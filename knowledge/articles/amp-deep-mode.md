# Amp Deep Mode

**URL:** https://ampcode.com/news/deep-mode

**Date:** January 28, 2026

**Summary:**
Amp introduces a new agent mode called "deep" that uses GPT-5.2-Codex. Unlike the "smart" mode which is collaborative and eager to edit, deep mode operates autonomously - reading files and moving through codebases for 5-15 minutes before making changes without constant check-ins.

**Key Features:**
- Uses GPT-5.2-Codex with tools tuned to the model's strengths
- Prefers autonomous problem-solving over pair programming
- Requires clear problem definition upfront
- Good at fixing issues in a single pass

**Use Cases:**
- Changing how Skills register MCP tools (managing multiple skill subsets)
- Fixing theme bugs with visual context (screenshots)

**Limitations:**
- Lazy about running commands and checking work
- Doesn't pay as much attention to AGENTS.md files as Opus does
- Area actively being improved

**Complementary Use:**
Works well alongside "smart" mode - use smart for collaboration and quick fixes, deep for autonomous problem-solving on well-defined tasks.
