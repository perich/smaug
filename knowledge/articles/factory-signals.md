# Signals: Toward a Self-Improving Agent

**Source:** Factory.ai
**Link:** https://factory.ai/news/factory-signals
**Date:** January 26, 2026
**Author:** Eno Reyes

## Overview

Factory's "Signals" system represents an approach to building self-improving AI agents that can autonomously manage code changes with minimal human intervention.

## Key Concepts

- **Privacy-Preserving Aggregation:** Signals uses a technique to extract failure trajectories from agents while maintaining privacy.
- **Actionable Work Items:** Failure patterns are transformed into actionable items in project management tools.
- **Autonomous PR Management:** Agents like "Droid" can:
  - Pick up work items
  - Create pull requests
  - Review their own work
  - Tag relevant engineers for final review
- **Quality Improvements:** The closed-loop approach has contributed to meaningful quality gains in agent performance.

## Significance

This represents progress toward agents that can self-supervise and improve their own processes, reducing the need for constant human oversight while maintaining quality control through code review mechanisms.
