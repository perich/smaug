Google released a significant upgrade to Gemini 3 Deep Think, a specialized reasoning mode designed for practical applications. The updated Deep Think enables researchers to interpret complex data and engineers to model physical systems through code.

A standout new capability allows users to convert hand-drawn sketches directly into 3D-printable designs. The model analyzes the drawing, builds the complex shape, and generates a file ready for 3D printing, bridging the gap between conceptual sketches and manufacturing.

## Key Capabilities

- Convert sketches to 3D-printable designs
- Model physical systems through code
- Interpret complex data for researchers
- Real-time shape analysis and file generation

## Availability

Currently rolling out to Google AI Ultra subscribers. Users can select the "Deep Think" option in the tools menu to access the functionality.
