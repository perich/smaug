# React Best Practices for Coding Agents

**Source:** https://vercel.com/blog/introducing-react-best-practices

**Author:** Vercel

## Overview

Vercel released `react-best-practices`, a repository containing React performance rules and evaluations specifically designed for use by coding agents.

## What It Covers

The repository includes:
- **React performance rules** - Best practices for optimal performance
- **Evals and regressions** - Tests to catch performance issues
- **Common pitfalls:**
  - Accidental waterfalls (cascading requests)
  - Growing client bundles
  - Other performance regressions

## Purpose

Designed to help autonomous coding agents:
- Understand React performance best practices
- Automatically catch performance regressions
- Maintain code quality standards
- Avoid common pitfalls during automated code generation/modification

## Relevance

This is part of a broader ecosystem where AI agents need to understand and follow established best practices when working with React codebases. It provides structured guidance that agents can follow during autonomous coding operations.
