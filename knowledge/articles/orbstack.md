# OrbStack

**URL:** https://orbstack.dev/

**Tagline:** Fast, light, simple Docker & Linux

**Description:**
OrbStack is a Docker Desktop alternative offering faster, lighter, and simpler container and Linux runtime. Described as developing "at lightspeed" compared to traditional Docker Desktop.

**Key Selling Points:**
- Lighter weight than Docker Desktop
- Faster performance
- Simpler to use
- Container and Linux support

**Context:**
Recommended as a Docker Desktop alternative for users new to Docker who don't have specific needs requiring Docker Desktop itself. Positions itself as the better default choice for Mac development environments.

**Availability:**
Available at orbstack.dev with download options and pricing information.
