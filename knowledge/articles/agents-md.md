# AGENTS.md

**Source:** https://agents.md/
**Status:** Open format, used by 60k+ open-source projects

## Overview

AGENTS.md is a simple, open format for guiding coding agents. Think of it as a README for agents—a dedicated, predictable place to provide context and instructions that help AI coding agents work on your project.

## Purpose

- Serve as a standardized reference for agents working on your codebase
- Provide clear instructions and context in a familiar format
- Improve agent performance by establishing shared understanding
- Make agent-friendly documentation accessible across projects

## Key Concept

Just as README.md helps human developers understand a project, AGENTS.md helps AI agents understand:
- Project structure and conventions
- Development guidelines
- Testing requirements
- Code quality standards
- Task prioritization

## Adoption

Used across 60,000+ open-source projects as the standard format for agent guidance, making it increasingly the de facto standard for AI-assisted development.

## Related Principles

The AGENTS.md format complements:
- Spec-driven development (breaking tasks into clear specifications)
- Functional core/imperative shell design patterns (architectural clarity)
- Clear, testable code design (agent-friendly codebase structure)
