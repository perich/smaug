## Overview

This comprehensive guide covers how to optimize your AGENTS.md file for AI coding agents. Bad AGENTS.md files can make your coding agent perform worse and cost you more tokens.

## Key Concepts

### Progressive Disclosure
Structure your instructions to reveal information progressively, allowing agents to learn what they need as they work rather than overwhelming them with all details upfront.

### Keep Instructions Focused
- Remove unnecessary context that bloats the file
- Prioritize actionable guidance over verbose explanations
- Use clear formatting and structure for easy scanning

### Token Efficiency
- Every token in AGENTS.md impacts agent performance and cost
- Remove redundant or outdated instructions
- Be concise while maintaining clarity

## Best Practices

1. **Organize by purpose** - Group related instructions logically
2. **Use formatting** - Headers, lists, and code blocks improve clarity
3. **Test your instructions** - Validate that agents understand your guidance
4. **Iterate regularly** - Update AGENTS.md based on agent behavior and results
5. **Clean up periodically** - Remove instructions that aren't being followed or aren't effective
