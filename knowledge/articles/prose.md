Prose is a natural language programming language designed to bridge human intent and computational orchestration. Rather than writing traditional imperative code, developers write natural language programs that are interpreted and executed by AI models.

## Key Insight

While an LSP (Language Server Protocol) editor support was initially developed, users don't interact directly with `.prose` files. Instead, AI models handle reading and writing `.prose` code perfectly. This seemingly paradoxical situation reveals an important principle: the structured `.prose` format enables models to be more expressive and specific compared to direct prompt-to-orchestration approaches.

## How It Works

- **Natural Language Programs**: Write programs in prose-like syntax
- **AI Interpretation**: Models read and generate `.prose` code
- **Orchestration**: Acts as an intermediary format between natural language prompts and execution

## Use Cases

- Cloud program execution with streaming output
- Complex task orchestration using natural language
- Integration of AI capabilities into larger systems
- Real-time programming without verbose traditional syntax

## Development Status

The project has evolved to focus on what actually matters: the model's ability to work with the prose format. While tooling support exists, the core value is in how transparently AI can work with prose as a programming format.
