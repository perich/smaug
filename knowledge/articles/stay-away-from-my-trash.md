# Stay Away From My Trash

**Source:** https://tldraw.dev/blog/stay-away-from-my-trash

**Author:** Steve Ruiz (via tldraw)

**Key Idea:** Steve Ruiz discusses how the "gift economy" around code contributions has fundamentally changed now that code is much easier to write. He argues that the idea of external/non-expert code contributions feels like an anachronism in the modern development landscape.

**Context:** This is a response to discussion about GitHub and the future of developer tooling, particularly examining how the ease of writing code has shifted the dynamics of open-source contributions and collaborative development.
