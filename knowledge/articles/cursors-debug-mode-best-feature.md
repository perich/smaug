An analysis of Cursor's Debug Mode feature and a broader thesis about the future of AI coding agents that instrument code during execution to understand and fix bugs more effectively.

## Key Takeaways

- Debug Mode helps agents formulate hypotheses about bugs systematically
- Instrumentation through logging enables agents to validate hypothesis
- Future AI agents should instrument code by default during execution
