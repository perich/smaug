# From Human Ergonomics to Agent Ergonomics

Author: Wes McKinney (@wesmckinn)
Date: January 20, 2026
URL: https://wesmckinney.com/blog/agent-ergonomics/

## Summary

An exploration of how building with agents fundamentally changes developer experience and preferences. As Wes McKinney builds more with agents, he finds himself moving away from Python as the primary development language.

## Key Themes

- The shift from human-centric ergonomics to agent-centric ergonomics
- How agent capabilities influence language and tool selection
- Rethinking developer experience for AI-driven development

## Context

This article reflects on a growing trend where agent-based development workflows are reshaping how developers think about language choice and development patterns.
